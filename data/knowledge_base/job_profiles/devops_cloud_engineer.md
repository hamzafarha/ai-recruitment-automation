# Job Profile — DevOps / Cloud Engineer

## Mission

Build and run the infrastructure and delivery pipelines that let teams ship software safely and often. The
DevOps/Cloud Engineer automates infrastructure, deployments and monitoring, and leads incident response.

## Responsibilities

- Provision cloud infrastructure as code.
- Build and maintain CI/CD pipelines.
- Operate container platforms (Docker, Kubernetes).
- Set up monitoring, logging and alerting; take part in on-call rotations.
- Improve security, reliability and cost of the platform.

## Must-have requirements

- **M1** Linux system administration and shell scripting.
- **M2** At least one cloud platform in production: AWS, Azure or GCP.
- **M3** Infrastructure as code: Terraform, CloudFormation, Pulumi or Ansible.
- **M4** CI/CD pipelines: Jenkins, GitLab CI, GitHub Actions or Azure DevOps.
- **M5** Containers: Docker, and Kubernetes or an equivalent orchestrator.

## Nice-to-have requirements

- **N1** Monitoring and observability: Prometheus, Grafana, Datadog, ELK, Splunk.
- **N2** A scripting language beyond shell: Python or Go.
- **N3** Security practices: secrets management, IAM, network policies.
- **N4** Cloud certifications (AWS, Azure, Kubernetes CKA).
- **N5** Configuration management: Ansible, Chef, Puppet.

## Equivalent and transferable skills

- AWS, Azure and GCP are equivalent for M2; certifications count as "Listed" evidence unless backed by projects.
- Terraform, CloudFormation and Pulumi are equivalent for M3.
- Jenkins, GitLab CI, GitHub Actions and Azure DevOps are equivalent for M4.
- A system administrator with strong Linux and scripting skills but no cloud or CI/CD meets M1 only: grade 1.
- A backend developer who maintained their team's pipelines and Docker setup meets M4 and M5 partially.

## Experience by level

- **Junior**: Linux, one cloud certification or lab, Docker projects.
- **Mid-level**: 2–5 years operating production infrastructure.
- **Senior**: 5+ years, designed the platform, led incident post-mortems, mentored others.

## Red flags

- Tool lists covering every cloud and every CI tool without a described environment.
- No mention of monitoring or incident handling for a mid-level or senior position.

## Role-specific interview questions

- "Walk me through a deployment pipeline you built, from commit to production."
- "A service is down at night. What do you check first, and in which order?"
- "How do you manage secrets in your infrastructure code?"
